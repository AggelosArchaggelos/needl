# Tattoo style guide

The former How it works page is now a beginner guide at the same /how-it-works URL. Navigation says Tattoo styles / Στιλ τατουάζ. Both homepages link to it.

Edit content/styles.json guide.summary, description, example and comparison in both en and el. The website reads this content directly; /api/config supplies it to the app. Style names remain English. Guide fields are optional for API compatibility; all current 12 styles have complete guides. The app shows retry when connected to an older API without guide content. Publish the website/API before the updated app when deployment is approved.

Descriptions explain visual characteristics, examples and overlaps. They are original editorial summaries, not rules that every artist must follow. Cultural traditions grouped in Tribal & Polynesian are explicitly distinguished, not treated as interchangeable. No medical or longevity guarantees are made. This first version uses written examples, not unapproved or misleading sample images.
